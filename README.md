# AI-Based Handwritten Exam Marks Extraction System

A Python-based project to extract examination marks from handwritten exam sheets using image processing and OCR.

## Project Status

Initial setup in progress.

## Planned Features

- Load supported examination sheet files.
- Preprocess images for improved recognition.
- Extract printed and handwritten marks.
- Validate extracted marks.
- Calculate totals and generate results.

## Development Setup

This project is being developed using Python and a virtual environment.

Setup instructions and dependencies will be added as development progresses.

## Privacy and Security

Do not commit student examination papers, personal information, API keys, service-account credentials, or other confidential files to GitHub.

```text
exam-marks-extraction/
├── app/        # Application modules
├── input/      # Input examination files (kept private)
├── output/     # Generated results
├── debug/      # Intermediate processing files
├── main.py     # Application entry point
├── .gitignore  # Files excluded from Git

```

## Development Setup

1. Install Python if it is not already installed.
2. Open this project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install project dependencies when they are introduced.
5. Run the application:

   ```powershell
   python main.py
   ```
